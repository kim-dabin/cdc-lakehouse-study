# 1회차 이전 PPT 보관

이 폴더의 PPT는 최종 강의안 채택 전에 만든 초안이다. 개인 설계 25분 등 이전 활동·시간표가 남아 있으므로 현재 수업 자료로 사용하지 않는다. 과거 작성·검증 기록은 파일 당시의 상태를 설명한다.

현재 수업은 강사가 사용하는 최종 강의안의 120분 흐름과 아래 문서를 기준으로 진행한다. 1회차에는 공통 환불 예제의 사전 예측과 원천·Kafka·Bronze 대조를 수행하고 개인 설계 확정은 3회차에 진행한다.
