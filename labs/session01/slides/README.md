# 1회차 강의용 PPT

[강의 자료 열기](session01-cdc-lakehouse-v3.pptx)

총 40장입니다. 1–35장은 휴식 5분을 포함한 120분 수업, 36–40장은 강사 사전 준비와 시연 명령, 원천 SQL 답안 부록입니다. 슬라이드 아래 시간은 수업 시작 후 경과 시간입니다. 28–29장은 같은 5분 설계 활동의 예시와 질문이며 시간을 두 번 배정하지 않습니다.

수업은 강사 맥미니 시연과 학생의 로컬 SQL·설계서 작성으로 진행합니다. 발표자 노트에 진행 질문, 예상 답, 시연 순서, 학생 작업과 시간 지연 시 진행 방법을 적었습니다. PowerPoint 또는 Keynote에서 발표자 노트를 함께 열어 사용하세요.

아키텍처 세 장은 데이터 흐름, 저장소와 메타데이터, 실행 환경을 각각 설명합니다. 포함된 그림의 편집 원본은 [docs/diagrams](../../../docs/diagrams/README.md)에 있습니다. 본문 텍스트와 표, SQL은 PPT에서 편집할 수 있습니다.

결제 100,000원, 환불 후 80,000원, 같은 환불 정정 후 70,000원을 관찰합니다. 환불 입력 뒤 **갱신 전 source와 Gold를 먼저 비교**하세요. 1회차에는 Airflow를 중지하고 Silver·Gold를 수동 갱신합니다. 학생의 개인 테이블을 수집기에 연결하는 설정은 이후 회차에서 진행합니다.

강의 화면을 만들 때 사용한 글꼴은 Apple SD Gothic Neo와 D2Coding입니다. 예제의 2026-10-19 날짜는 합성 데이터이며 실제 강의 일정이 아닙니다. 프로젝트 발표는 8회 스터디가 끝난 뒤 별도 일정으로 진행합니다.
